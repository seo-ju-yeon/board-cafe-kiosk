# TS 001. 시연 환경에서 음성 녹음이 끝나지 않은 문제

## 문제 상황

AI 게임 안내 화면은 사용자의 말을 녹음한 뒤 서버로 전송합니다.
처음에는 일정 시간 소리가 없으면 녹음을 자동으로 끝내도록 구현했습니다.

혼자 개발할 때는 동작했지만, 학원 시연에서는 주변 소음 때문에 녹음이 끝나지 않았습니다.
녹음이 종료되어야 서버로 전송할 수 있어 AI 안내까지 진행하기 어려웠습니다.

## 변경한 방법과 이유

팀 논의에서 제가 **마이크 버튼을 다시 눌러 녹음을 끝내는 방식**을 제안했습니다.
무음 구간에 의존하지 않고 사용자가 종료 시점을 정하도록 바꿨습니다.
화면에도 말을 마친 뒤 버튼을 한 번 더 누르도록 안내했습니다.

버튼을 한 번 더 눌러야 하는 불편은 있지만, 잡음이 있는 환경에서도 녹음 종료 시점을 직접 정할 수 있습니다.

## 구현

[ai.js의 toggleListening()](../../src/main/resources/static/js/kiosk/ai.js#L88)에서 녹음 상태에 따라 시작과 종료를 나눕니다.

```javascript
if (isListening) {
    stopRecording();
} else {
    await startListening();
}
```

`stopRecording()`은 녹음기를 멈추고 마이크 트랙을 종료합니다.
이후 `onRecordingStop()`에서 녹음 데이터를 묶어 서버로 전송합니다.

## 확인 결과와 남은 점

변경 후 잡음이 많은 학원에서도 버튼으로 녹음을 종료할 수 있음을 확인했습니다.
다양한 브라우저와 마이크에서의 호환성, 장시간 녹음은 추가 확인이 필요합니다.
