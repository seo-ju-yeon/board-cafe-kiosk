# TS 003. 임베딩된 게임이 검색되지 않아 기준을 조정한 경험

## 문제 상황

AI 게임 안내를 구현할 때 검색 유사도 기준을 `0.7`로 설정했습니다.
처음에는 게임을 질문하면 설명을 안내하도록 만들었지만, 시연 중 예상한 게임이 검색되지 않았습니다.

## 확인 과정과 변경

처리 단계를 추적하며 벡터 DB에 게임 정보가 임베딩되어 저장된 것을 확인했습니다.
데이터가 저장되어 있는데도 검색되지 않아 유사도 기준을 살펴봤습니다.
디버깅 중 기준을 `0.7`에서 `0.3`으로 낮추자 관련 게임이 검색되었습니다.

[AiService](../../src/main/java/org/example/board_cafe_kiosk_2603/ai/AiService.java#L37)에서는 현재 다음 설정을 사용합니다.

```java
private static final double SIMILARITY_THRESHOLD = 0.3;
private static final int TOP_K = 3;
```

질문과 유사한 문서를 최대 3개 검색하고, 그 내용을 LLM에 전달해 답변을 생성합니다.
검색된 게임명과 점수는 로그로 출력하도록 구현했습니다.

## 확인 결과와 한계

기준을 낮춘 뒤 관련 게임이 검색되는 것을 확인했습니다.
이후에는 “종치는 게임이 뭐지?”처럼 게임명을 직접 말하지 않은 질문에도 게임 안내가 나오는 것을 확인했습니다.

`0.3`은 디버깅 중 조정한 값이며, 별도 평가로 찾은 최적값은 아닙니다.
질문별 점수와 검색 결과를 비교한 기록은 없어, 검색 정확도가 얼마나 달라졌는지는 측정하지 못했습니다.
기준을 낮추면 관련 없는 게임도 검색될 수 있으므로 대표 질문으로 비교할 필요가 있습니다.

검색 결과가 없을 때는 정해진 안내 문장을 사용하도록 LLM에 요청합니다.
응답 문구는 프롬프트에 의존하며, 검색 누락도 매장에 등록되지 않은 게임으로 안내할 수 있다는 한계가 있습니다.

## 개선할 점

게임명·특징·플레이 인원에 관한 질문과 매장에 없는 게임 질문을 준비해 비교하려고 합니다.
기대하는 게임, 실제 검색된 게임, 점수와 최종 답변을 함께 기록해 검색 기준을 검토할 계획입니다.
